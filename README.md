# 福师大课表助手

Android 8.0 及以上。非学校官方应用。账号和课表保存在本机，密码不持久化。

[下载最新版](https://github.com/Orang1ver/fjnu-schedule-assistant/releases/latest)

安装 1.0.2 后可在「设置 → 软件更新」检查、下载并安装后续版本。

更新源：`https://github.com/Orang1ver/fjnu-schedule-assistant/releases/latest/download/latest.json`

更新包校验 SHA-256、包名、版本和签名，覆盖安装保留用户设置。
GitHub 无法访问时，可在客户端改用自建 HTTPS 更新镜像。
