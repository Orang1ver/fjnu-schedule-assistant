# 福师大课表助手

Android 8.0 及以上，非学校官方应用。账号和课表在本机保存，密码不持久化。

[下载最新版 APK](https://github.com/Orang1ver/fjnu-schedule-assistant/releases/latest/download/app-release.apk) · [发布记录](https://github.com/Orang1ver/fjnu-schedule-assistant/releases)

支持今日安排、每周课表、通知/闹钟提醒、自定义课表同步、JSON 导出与两套玻璃主题。

1.0.3 修复更新检查遇到断流时直接失败，新增重试及备用更新入口；流畅档移除实时背景滤镜，并提供可关闭的帧耗时诊断。首次请直接覆盖安装本版 APK，再通过「设置 → 软件更新」安装后续版本。账号、课表和设置保留。
